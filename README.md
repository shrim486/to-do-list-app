# Advanced To-Do List App

A modern and interactive To-Do List application built using HTML, CSS, and JavaScript.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Task priority levels (Low, Medium, High)
* Task creation date and time
* Task counter
* Completed task counter
* Dark mode toggle
* Local Storage support (tasks remain after page refresh)
* Clear All Tasks option
* Responsive and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## How to Use

1. Enter a task in the input field.
2. Select the priority level.
3. Click the **Add** button or press **Enter**.
4. Click a task to mark it as completed.
5. Use the **Delete** button to remove a task.
6. Use **Dark Mode** for a different theme.
7. Use **Clear All** to remove all tasks.

## Project Purpose

This project was created to practice front-end web development concepts including DOM manipulation, event handling, local storage, and responsive UI design.
