# To-Do List App

## Objective
To create an interactive To-Do List using JavaScript DOM Manipulation.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add Tasks
- Delete Tasks
- Mark Tasks as Completed
- Responsive Design

## DOM Methods Used
- getElementById()
- createElement()
- appendChild()
- addEventListener()
- remove()

## Conclusion
This project demonstrates JavaScript DOM manipulation and event handling.
